## Question 2
**Query:** How is Mean Squared Error (MSE) calculated?

### Expected Answer
> Mean Squared Error (MSE) is calculated by taking the difference between the actual value and the model prediction, squaring that difference, and then averaging it across the entire dataset.

### RAG Generated Answer (Mistral)
 To calculate the Mean Squared Error (MSE), follow these steps:

1. Determine your dataset, which consists of actual values (y(i)) and model predictions (y ̂(i)).
2. For each data point, find the difference between the actual value and the model prediction (difference = y(i) - y ̂(i)).
3. Square each difference calculated in step 2: (difference)^2.
4. Average the squared differences across the entire dataset by summing up all the squared differences and dividing by the number of data points (N): MSE = (1/N) * Sum[(difference)^2].

The final result, MSE, represents the average squared difference between actual values and model predictions. [Source 1, Source 2]
